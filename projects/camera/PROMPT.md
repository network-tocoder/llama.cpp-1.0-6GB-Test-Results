# 3D vintage film camera

> **Note:** this prompt was reconstructed from the finished build and the video. The original wording may differ slightly.

```
Build an interactive 3D vintage film camera in a single index.html file using Three.js.
Clicking the shutter plays a sound, fires a flash and advances the frame counter.
A second shot is blocked until you advance the film by dragging the lever, like a real camera.
Zoom the lens from 35 to 90 mm, switch between black, chrome and olive finishes,
and add an exploded view that separates every part with a label and then reassembles it.
When finished, check the file is complete and valid.
```
